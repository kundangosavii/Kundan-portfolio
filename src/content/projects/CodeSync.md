## Overview

CodeSync is a developer-focused code analysis platform that goes beyond basic static analysis by transforming raw code structure into actionable engineering insights. It parses JavaScript/TypeScript repositories, builds dependency graphs, and performs advanced analyses such as impact detection, circular dependency identification, and complexity scoring. The system enables developers to answer critical questions like 'What breaks if I change this file?' and 'Which parts of the codebase are most risky?'. It includes both a CLI tool and an interactive dashboard for visualization, along with an AI-powered layer that generates architecture summaries, risk reports, and refactoring suggestions. Designed to work on real-world repositories, CodeSync emphasizes decision-making over data display, making it a practical tool for improving code quality and maintainability.
